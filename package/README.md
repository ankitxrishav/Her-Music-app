# Her Music - Prebuilt Packages 📦

Prebuilt APKs for **Her Music** (com.fenrir.her).

## Available Packages

| Package | Architecture | Size | Compatibility | Download |
|---------|--------------|------|---------------|----------|
| **Her-Music-arm64-v8a.apk** | ARM64 (64-bit) | ~47 MB | 99% of modern Android devices (Snapdragon, MediaTek, Google Tensor, Exynos) | [Download](Her-Music-arm64-v8a.apk) |
| **Her.apk (Universal)** | All ABIs | ~121 MB | All Android architectures (ARM64, ARMv7, x86, x86_64) | Generated via `./gradlew assembleUniversalFossDebug` |

## Installation Instructions

1. Download `Her-Music-arm64-v8a.apk` onto your Android phone.
2. Tap the file in your Downloads or File Manager.
3. If prompted, allow "Install unknown apps" for your browser or file manager.
4. Tap **Install** and open **Her Music** 💕!
5. In the Couple Space tab, exchange codes with your partner to link spaces immediately.
